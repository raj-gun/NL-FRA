## Overview 📖  
**NL-FRA** (NonLinear Frequency Response Analysis) is a MATLAB package for nonlinear frequency-domain analysis using Nonlinear Output Frequency Response Functions (NOFRFs). The package implements a data-driven least-squares (LS) approach that estimates NOFRFs directly from input-output data. It therefore does not require a specific time-domain model structure: the data can be obtained experimentally or generated using any suitable dynamic model of the nonlinear system.

For a nonlinear system, the output spectrum can be decomposed into contributions from different nonlinear orders,

\[
Y(j\omega)=\sum_{n=1}^{N}Y_n(j\omega), \qquad
Y_n(j\omega)=G_n(j\omega)U_n(j\omega),
\]

where \(G_n(j\omega)\) is the \(n\)-th order NOFRF, \(U_n(j\omega)\) is the corresponding nonlinear input composition, and \(Y_n(j\omega)\) is the \(n\)-th order Output Frequency Response Function (OFRF).

### Features  
- **Data-driven NOFRF evaluation**: Estimates NOFRFs directly from input-output data using the LS method.
- **General band-limited inputs**: Determines the frequency ranges over which each nonlinear order contributes and evaluates the corresponding NOFRFs.
- **Discrete multi-tone inputs**: Supports probing signals containing several discrete frequency components and determines the resulting nonlinear frequency components.
- **Sinusoidal probing and nonlinear transmissibility**: Supports frequency-sweep analysis at the excitation frequency and generated harmonics.
- **NOFRF validation**: Reconstructs the output spectrum from evaluated NOFRFs and compares it with an independently generated or measured response.
- **OFRF decomposition**: Computes the individual nonlinear-order contributions \(Y_n(j\omega)\) to the total output spectrum.
- **Visualisation**: Includes routines for plotting input compositions, valid frequency regions, NOFRFs, OFRFs and reconstructed responses.
- **Model-independent workflow**: Can be used with experimental data or with data generated by differential-equation, NARX or other suitable nonlinear dynamic models.

NL-FRA currently supports **single-input single-output (SISO)** nonlinear systems.

## Getting Started 🚀  

### Prerequisites  
- MATLAB.
- The core NL-FRA routines use standard MATLAB functionality.
- The NARX identification example additionally uses the [NonSysID](https://github.com/raj-gun/NonSysID) package.

### Installation  
1. Clone the repository:
   ```bash
   git clone https://github.com/raj-gun/NL-FRA.git
   ```
   or manually download the repository.

2. In MATLAB, either:
   - add the `NOFRF` folder to the MATLAB path permanently using [`pathtool`](https://uk.mathworks.com/help/matlab/ref/pathtool.html), or
   - use `addpath` in your script:
     ```matlab
     addpath('path_to_NL-FRA/NOFRF')
     ```

### Documentation
Brief documentation explaining the main NOFRF functions, reconstruction/validation functions and a complete code structure is given in the [`doc`](/doc) folder.

### Examples
- **General band-limited input using an identified NARX model**: [`Examples/NARX_band_limited_NOFRF.m`](Examples/NARX_band_limited_NOFRF.m).
- **General band-limited input using a nonlinear model**: [`Examples/Lang_Billings_2005_exmpl_5_1.m`](Examples/Lang_Billings_2005_exmpl_5_1.m).
- **Discrete multi-tone input**: [`Examples/Multi_tone_NOFRF.m`](Examples/Multi_tone_NOFRF.m).
- **NOFRF-based nonlinear transmissibility analysis**: [`Examples/Transmisibility_NOFRF.m`](Examples/Transmisibility_NOFRF.m).

The `Examples/Figures` folder contains the corresponding generated figures, while `Examples/Data` contains data used by the data-driven NARX example.

## Main Functions

| Function | Purpose |
|---|---|
| [`SISO_NOFRF`](NOFRF/SISO_NOFRF.m) | Main SISO workflow for general band-limited or sinusoidal probing inputs. |
| [`SISO_NOFRF_comp`](NOFRF/SISO_NOFRF_comp.m) | Main SISO workflow for discrete multi-tone probing inputs. |
| [`NOFRF_LS2`](NOFRF/NOFRF_LS2.m) | LS evaluation of NOFRFs for band-limited/sinusoidal inputs. |
| [`NOFRF_LS2comp`](NOFRF/NOFRF_LS2comp.m) | LS evaluation of NOFRFs for discrete multi-tone inputs. |
| [`nonlinear_freq_range`](NOFRF/nonlinear_freq_range.m) | Determines nonlinear output-frequency ranges for a band-limited input. |
| [`nonlinear_freq_comp`](NOFRF/nonlinear_freq_comp.m) | Determines nonlinear output-frequency components for a discrete multi-tone input. |
| [`nofrf_test`](NOFRF/nofrf_test.m) | Reconstructs OFRF contributions and the total output using evaluated NOFRFs for a band-limited/sinusoidal input. |
| [`nofrf_test_comp`](NOFRF/nofrf_test_comp.m) | Reconstructs OFRF contributions and the total output for a discrete multi-tone input. |

## Basic Workflow

The standard data-driven workflow is:

1. Define a probing input `u` and choose the nonlinear orders `nl_ord_set`.
2. Apply several constant input scalings `A` to the same probing input and obtain the corresponding output responses in the columns of `Y`.
3. Obtain an independent output `y_test` at the test amplitude `Amp`.
4. Evaluate and validate the NOFRFs using `SISO_NOFRF` for a band-limited/sinusoidal input, or `SISO_NOFRF_comp` for a discrete multi-tone input.
5. Use the returned `G_LS_2` and the `nofrf_test`/`nofrf_test_comp` routines when NOFRF-generated responses are required separately from the full evaluation workflow.

See the [Example Code Structure](doc/Example_code_structure.md) for a step-by-step MATLAB template.
