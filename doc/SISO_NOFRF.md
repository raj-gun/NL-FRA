# `SISO_NOFRF`

`SISO_NOFRF` provides the main NL-FRA workflow for evaluating, testing and visualising SISO Nonlinear Output Frequency Response Functions (NOFRFs) from input-output data generated using a general band-limited or sinusoidal probing input.

For discrete multi-tone probing inputs, use `SISO_NOFRF_comp`, which follows the same workflow but determines the valid nonlinear frequency components using the discrete input-frequency set.

---

## Signatures

### General band-limited or sinusoidal input

```matlab
[Norm_SSE_abs_LS_2,Norm_SSE_arg_LS_2,Norm_SSE_LS_2, ...
 Fe_n_Yn,Fe_p_Yn,Y_NOFRF_MLS_n,Y_NOFRF_LS_2,G_LS_2, ...
 sse,Y_model] = ...
    SISO_NOFRF(Fs,Ts,tspan,fftn,f1,f2,u_nofrf,A,Amp, ...
    nl_ord_set,gc,harm_inpt,lw,norm,displ,Y,y_test);
```

### Discrete multi-tone input

```matlab
[Norm_SSE_abs_LS_2,Norm_SSE_arg_LS_2,Norm_SSE_LS_2, ...
 Fe_n_Yn,Fe_p_Yn,Y_NOFRF_MLS_n,Y_NOFRF_LS_2,G_LS_2, ...
 sse,Y_model] = ...
    SISO_NOFRF_comp(Fs,Ts,tspan,fftn,pos_freq_comp,u_nofrf,A,Amp, ...
    nl_ord_set,gc,harm_inpt,lw,norm,displ,Y,y_test);
```

## Parameters

| Name | Type | Required | Description |
|---|---|---:|---|
| `Fs` | `double` | Yes | Sampling frequency in Hz. |
| `Ts` | `double` | Yes | Sampling period in seconds. Normally `Ts = 1/Fs`. |
| `tspan` | `vector` | Yes | Time vector corresponding to the probing input and output responses. |
| `fftn` | `int` | Yes | FFT length used by the NOFRF evaluation. |
| `f1` | `double` | `SISO_NOFRF` only | Upper edge of the positive-frequency input band in Hz. For sinusoidal probing use `f1 = f2`. |
| `f2` | `double` | `SISO_NOFRF` only | Lower edge of the positive-frequency input band in Hz. The implementation requires `f1 >= f2`. |
| `pos_freq_comp` | `vector` | `SISO_NOFRF_comp` only | Positive discrete frequency components of the multi-tone probing input in Hz. |
| `u_nofrf` | `vector` | Yes | Unit/reference probing input used to construct the nonlinear input compositions. |
| `A` | `vector` | Yes | Constant amplitude scalings applied to `u_nofrf` to generate the evaluation data. Each element corresponds to one column of `Y`. |
| `Amp` | `double` | Yes | Independent test amplitude used with `y_test` for NOFRF validation/reconstruction. |
| `nl_ord_set` | `vector` | Yes | Nonlinear orders to evaluate, e.g. `1:4` or `1:9`. The maximum value defines the highest considered order. |
| `gc` | `char` | Yes | Plot colour specification passed to the plotting routines, e.g. `'b'`. |
| `harm_inpt` | `0/1` | Yes | Plotting/input-mode flag used by the validation and visualisation routines. Use `0` for a general band-limited input and `1` for harmonic/discrete probing examples. |
| `lw` | `double` | Yes | Plot line width. |
| `norm` | `0/1` | Yes | Normalisation flag used by the plotting routines. |
| `displ` | `vector` | Yes | Display controls described below. A three-element vector is supported for backward compatibility; in that case NOFRF magnitude/phase plots remain enabled. |
| `Y` | `matrix` | Yes | Output responses used for LS evaluation. Column `i` is the response to input `A(i).*u_nofrf`. |
| `y_test` | `vector` | Yes | Independent output response at input amplitude `Amp`, used for validation. |

### Display controls

`displ` can contain four elements:

| Element | Function |
|---|---|
| `displ(1)` | Display LS evaluation information and normalised SSE values. |
| `displ(2)` | Display NOFRF prediction/validation plots. |
| `displ(3)` | Display input compositions $`U_n`$, output spectra and valid-frequency regions. |
| `displ(4)` | Display NOFRF magnitude/phase plots. |

For example, `displ = [1,1,1,1]` enables all available output, while `displ = [0,0,0,0]` is useful when repeatedly evaluating local NOFRFs inside a frequency sweep.

---

## Returns

| Output | Description |
|---|---|
| `Norm_SSE_abs_LS_2` | Normalised spectral error measure associated with the output-magnitude comparison generated during validation. |
| `Norm_SSE_arg_LS_2` | Normalised spectral error measure associated with the output-phase comparison generated during validation. |
| `Norm_SSE_LS_2` | Combined/complex spectral validation error returned by the prediction routine. |
| `Fe_n_Yn` | Negative frequency-error information returned by the NOFRF prediction/validation routine. |
| `Fe_p_Yn` | Positive frequency-error information returned by the NOFRF prediction/validation routine. |
| `Y_NOFRF_MLS_n` | Individual nonlinear-order output-frequency contributions generated by the NOFRF validation routine. |
| `Y_NOFRF_LS_2` | Total output spectrum reconstructed from the evaluated NOFRFs. |
| `G_LS_2` | Evaluated NOFRFs. Columns correspond to nonlinear orders and rows to frequency bins retained by the evaluation. |
| `sse` | LS fitting errors returned by the NOFRF evaluation stage: total, real-part and imaginary-part normalised SSE values. |
| `Y_model` | Spectrum of the independent validation response used by the prediction routine. |

---

## Algorithm (High-Level)

1. **Determine valid frequency regions**: For a band-limited input, `nonlinear_freq_range` determines the frequency sets in which each nonlinear input composition can be non-zero. For a multi-tone input, `nonlinear_freq_comp` generates the corresponding discrete nonlinear frequency components.
2. **Construct nonlinear input compositions**: The FFTs of `u_nofrf.^n` are scaled according to the NOFRF input-composition definition.
3. **Form the LS information matrix**: At each frequency, only nonlinear orders whose input compositions are valid at that frequency are retained.
4. **Estimate NOFRFs**: The real and imaginary parts of the frequency-domain equations are solved using least squares.
5. **Reconstruct the output**: The evaluated $`G_n(j\omega)`$ functions are combined with the test input compositions to generate $`Y_n(j\omega)`$ and the total NOFRF output.
6. **Validate and visualise**: The reconstructed response is compared with `y_test`; optional plots show the valid frequency spaces, $`U_n`$, $`G_n`$ and $`Y_n`$.

## Example Usage: General Band-Limited Input

```matlab
Fs = 50;
Ts = 1/Fs;
fftn = 1024;
tspan = (0:fftn).*Ts;

f1 = 6.5;
f2 = 3.5;
u = (3/(2*pi)).*(sin(2*pi*f1.*tspan)-sin(2*pi*f2.*tspan))./tspan;
u(tspan == 0) = 3*(f1-f2);
u = u(:);

nl_ord_set = 1:4;
A = linspace(0.9,0.5,max(nl_ord_set))';
Amp = 1;

% Y must contain the system outputs generated by A(i).*u.
% y_test is an independent system output generated by Amp.*u.

[~,~,~,~,~,Yn,Y_NOFRF,G_LS_2,sse,~] = ...
    SISO_NOFRF(Fs,Ts,tspan,fftn,f1,f2,u,A,Amp, ...
    nl_ord_set,'b',0,0.5,0,[1,1,1,1],Y,y_test);
```

## Example Usage: Discrete Multi-Tone Input

```matlab
Fs = 1000;
Ts = 1/Fs;
fftn = 10000;
tspan = (0:fftn).*Ts;

pos_freq_comp = [5,7,8];
u = cos(2*pi*5*tspan) + cos(2*pi*7*tspan) + cos(2*pi*8*tspan);
u = u(:);

nl_ord_set = 1:5;
A = linspace(1.3,1.2,max(nl_ord_set))';
Amp = 1.4;

[~,~,~,~,~,Yn,Y_NOFRF,G_LS_2,sse,~] = ...
    SISO_NOFRF_comp(Fs,Ts,tspan,fftn,pos_freq_comp,u,A,Amp, ...
    nl_ord_set,'b',1,0.5,0,[1,1,1,1],Y,y_test);
```

---

## Notes

- The LS method relies on several responses generated using constant amplitude scalings of the same probing input.
- `Y` must contain one response per amplitude factor in `A`.
- For reliable evaluation, use enough independent amplitude scalings to resolve the nonlinear orders contributing at a given frequency.
- The valid frequency support is sparse and order dependent. NL-FRA removes invalid $`U_n(j\omega)`$ terms before solving the LS equations.
- `SISO_NOFRF` is used for continuous band-limited support and also for the single-tone/sinusoidal case by setting `f1 = f2`.
- `SISO_NOFRF_comp` is intended for a known set of discrete positive-frequency components.
