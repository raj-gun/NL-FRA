# NL-FRA Examples

This folder contains example scripts demonstrating the main SISO workflows available in **NL-FRA** for evaluating and validating Nonlinear Output Frequency Response Functions (NOFRFs), together with NOFRF-based transmissibility analysis.

## Examples

- [`NARX_band_limited_NOFRF.m`](./NARX_band_limited_NOFRF.m)  
  Data-driven example based on the coupled electric-drives benchmark. A polynomial NARX model is first identified using `NonSysID`, independently validated, and then excited using a general band-limited probing input. The resulting input-output data are used to evaluate and validate the first four NOFRFs.

- [`NonSysID_electro_mechanical_band_limited_NOFRF.m`](./NonSysID_electro_mechanical_band_limited_NOFRF.m)  
  Identifies a polynomial NARX model from the electro-mechanical system data used in the `NonSysID` examples, excites the identified model using a general band-limited input, and evaluates the first four NOFRFs. This example requires the `NonSysID` package.

- [`Lang_Billings_2005_exmpl_5_1.m`](./Lang_Billings_2005_exmpl_5_1.m)  
  Reproduces the general band-limited NOFRF example associated with Figure 5 of Lang and Billings (2005). A nonlinear oscillator is simulated using the band-limited input defined in that work, and the first four NOFRFs are evaluated.

- [`Multi_tone_NOFRF.m`](./Multi_tone_NOFRF.m)  
  Demonstrates NOFRF evaluation for a discrete multi-tone input using a Duffing oscillator excited at 5, 7 and 8 Hz. The example uses `SISO_NOFRF_comp` to determine the nonlinear frequency components generated by the discrete input frequencies and evaluates the first five NOFRFs.

- [`Transmisibility_NOFRF.m`](./Transmisibility_NOFRF.m)  
  Demonstrates nonlinear transmissibility analysis using local NOFRFs evaluated over a sinusoidal frequency sweep. The script compares the actual and NOFRF-generated transmissibilities at the excitation frequency and at the third harmonic, and also shows the contribution of each nonlinear order to the output response.

## Supporting files

- [`Data`](./Data/) contains data used by the data-driven examples, including the coupled electric-drives benchmark data.
- [`Figures`](./Figures/) contains figures generated by the example scripts.
- [`ode4.m`](./ode4.m) provides the fixed-step fourth-order Runge-Kutta solver used by the ODE-based examples.

## Running the examples

Before running an example, add the NL-FRA `NOFRF` folder to the MATLAB path. Some scripts currently contain local absolute paths and may therefore need the path definitions at the top of the script to be changed for your system.

The examples that identify or simulate NARX models additionally require the [`NonSysID`](https://github.com/raj-gun/NonSysID) package to be available on the MATLAB path.

For a general step-by-step workflow, see the [`NL-FRA documentation`](../doc/README.md) and the [`Example Code Structure`](../doc/Example_code_structure.md).
